# Mission A+ Ekonomi

Latihan soalan percubaan SPM Ekonomi 3767 (Kertas 1) dari 13 set negeri.
Rekod murid disimpan dalam pelayar peranti masing-masing (tiada pelayan, tiada data dihantar ke mana-mana).

Cara guna di GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.
Buka `index.html` melalui pautan Pages (bukan klik dua kali fail, kerana soalan dimuatkan melalui fetch).
